# 開発ロードマップ

日数は学習時間を含む目安。各フェーズは、完了条件を満たしてから次へ進む。

## 現状サマリー

2026年6月21日時点の方針と進捗。

- 配布対象はApple App Storeのみ
- Android、Web、desktopはMVP対象外
- FlutterプロジェクトはiOS向けに整理済み
- 時計表示、反射アニメーション、画面サイズ変更時の補正、バックグラウンド時のアニメーション停止は実装済み
- `dart format --output=none --set-exit-if-changed lib test`、`flutter analyze`、`flutter test`は成功済み
- Xcode 26.5とiOS 26.5 Simulatorで起動確認済み

## 直近タスクリスト

まずは開発環境をiOSで実行できる状態に戻し、その後にMVPに必要な未実装機能を小さく進める。

1. [x] Xcode本体をMac App Storeからインストールする
2. [x] `sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer`を実行する
3. [x] `sudo xcodebuild -runFirstLaunch`を実行する
4. [x] `xcodebuild -downloadPlatform iOS`でiOS Simulatorランタイムを導入する
5. [x] `flutter doctor -v`でiOS関連の重大エラーを解消する
6. [x] `open -a Simulator`と`flutter run -d ios`で初期画面を起動確認する
7. [ ] iOSで縦向き、横向き、復帰時の表示崩れを手動確認する
8. [ ] 常時点灯の実装方式を決める
9. [ ] SEをMVPに入れるか判断する
10. [x] `AppSettings`の最小モデルを定義する
11. [x] 設定画面の最小UIを作る
12. [x] 設定保存を端末内に実装する
13. [ ] App Store配布用の正式名称、Bundle ID、アイコン方針を決める

**目安:** 2〜4日

**状態:** 進行中

### 作業

- [ ] iPhone実機でFPS、発熱、電池消費を確認する

### 完了条件

- 30分以上連続動作して破綻しない
- 画面回転、復帰、サイズ変更で図形が画面外に残らない

### 判断ポイント

- 標準描画APIで性能が十分か
- 常時点灯時の発熱と消費電力を許容できるか
