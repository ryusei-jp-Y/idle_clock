# 時計更新とアニメーション更新を分離する

## 状態

採用

## 背景

時計は1秒ごとに更新すればよい一方、反射アニメーションは滑らかに見せるため
画面のリフレッシュレートに合わせて更新する必要がある。両方を同じ`setState`で
更新すると、時計を含む画面全体が毎フレーム再構築される。

## 判断

- 時計は`Timer`を使い、次の秒の境界に合わせて時計Widgetだけを更新する
- アニメーションは`AnimationController`で進める
- 動く図形は`CustomPainter`で描画し、`RepaintBoundary`内だけを再描画する
- 反射計算はWidgetから分離し、位置・速度・領域サイズを受け取る純粋関数にする

## 結果

- 時計のWidgetツリーは毎フレーム再構築されない
- 反射計算を端への衝突や画面サイズ変更ごとにユニットテストできる
- バックグラウンド移行時にアニメーションだけを停止できる
- 時計とアニメーションの責務が別ファイルになり、変更範囲を限定できる
