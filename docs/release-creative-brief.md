# リリース用クリエイティブブリーフ

2026年6月24日時点のアプリ仕様をもとに、正式名称、アイコン、App Store掲載画像、説明文を作るための元資料。

## 1. アプリの核

### 一言でいうと

横向きのiPhoneに置いて眺める、反射する光のオブジェクトと電子音が心地よいミニマル時計。

### 体験価値

- 時刻を確認しながら、画面内を動くオブジェクトをぼんやり眺められる
- 壁やオブジェクト同士の衝突で、波紋、色変化、短い電子音が起きる
- 作業机、ベッドサイド、休憩中に置いておける
- 機能はシンプルで、操作要素は目立たせない

### 主要機能

- 大きく読みやすいデジタル時計
- 12時間 / 24時間表記の切り替え
- 秒表示のオン / オフ
- 横画面限定
- 最大4つの移動オブジェクト
- 壁反射、オブジェクト同士の反射
- 衝突時の波紋、色変化、短い「ピーン…」というSE
- メイン画面表示中の常時点灯
- 設定保存

2. Drift Clock

## 5. アイコン制作ブリーフ

### 目的

小さいサイズでも、時計アプリであり、光る円形オブジェクトが反射する体験を想起できること。

### 構成案

- 背景: ほぼ黒に近い深いネイビー
- 主役: 中央または右上寄りの二重丸オブジェクト
- 補助要素: 小さな波紋、点で構成された時刻の断片、角に近い反射点
- 色: 青紫、淡いシアン、白に近い薄紫
- 質感: フラット寄り。過度な光沢や3D感は避ける

### アイコンで避けること

- 時刻を細かく描き込みすぎる
- 文字ロゴに依存する
- 端末本体、画面枠、スクリーンショットをそのまま使う
- 透明背景
- 既存ブランド風のロゴ表現

## 6. ストア掲載画像ブリーフ

Apple公式情報では、App Storeの商品ページにスクリーンショットは最大10枚、App Previewは最大3本掲載できる。App Previewは最大30秒。最初の1〜3枚が検索結果でも重要になるため、最初の画像でアプリの核を伝える。

### スクリーンショット方針

- アプリが横画面限定なので、掲載画像も横画面UIを軸にする
- 背景はアプリ実画面を使い、上に短いコピーを載せる
- コピーは1枚につき1メッセージ
- 実際に存在しない機能を見せない

### 推奨構成

| 枚数 | 見せる内容 | コピー案 |
|---|---|---|
| 1 | 時計と移動オブジェクトのメイン画面 | 置いて眺める、静かな時計 |
| 2 | 波紋と色変化が出ている瞬間 | 反射のたびに、光と音が広がる |
| 3 | ベッドサイド / 作業机利用を想起する構成 | 横向きに置いて、時間を眺める |
| 4 | 設定画面 | 秒表示やオブジェクト数を調整 |
| 5 | 4オブジェクト表示 | 画面の中で、光が跳ね返る |

### App Preview案

- 長さ: 10〜20秒程度
- 内容: 時計表示、反射、波紋、SEの雰囲気、設定画面を短く見せる
- 注意: `simctl recordVideo`は映像のみ。音声込みで作る場合はOBS、ScreenFlow、またはシステム音声録画環境を使う
