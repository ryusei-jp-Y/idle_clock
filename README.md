# Idle Clock

動き続けるビジュアルを眺めながら時間を確認できる時計アプリです。

`Idle Clock`は開発用の仮称です。正式なサービス名が決まり次第、表示名を変更します。

## 対象プラットフォーム

- MVP: iOS / Android
- MVP後: macOS

## 技術方針

- Flutter / Dart
- 端末内で完結するローカルファースト構成
- MVPではバックエンド、認証、データベースを持たない
